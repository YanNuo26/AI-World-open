# 文件结构

> **本文档动态更新**：新增/删除/移动/改名后，请顺手更新这里。
> **命名原则**：目录名**看名字就知道作用，尽量用中文**；层次控制在 3 层以内。
> **例外**：服务器或依赖规定死的目录名不改（`logs/`、`libraries/`、`versions/`、`node_modules/`），它们都在 `服务器/` 或根目录下，见标注。
> **根目录只留重要文件**，源码 / 脚本 / 服务器 / 文档 / 测试 都在各自子目录里。

## 一、根目录（只留这些）

| 文件 | 作用 |
| --- | --- |
| `AGENTS.md` | **给开发用 AI 的协作说明**（术语、怎么跑、约定），只做指引 |
| | 放根目录是为了让 AI 编码工具**自动发现**（多数工具只读仓库根目录） |
| `config.json` | **全部可配置项**：连接 / RCON / ai 名字 / 行为开关 / 默认建筑（旧格式自动兼容） |
| `skins.json` | 皮肤登记（需服务器装皮肤插件才生效） |
| `ais.json` | 多 ai 注册表（**运行时生成**，主 ai 启动会重置） |
| `package.json` / `package-lock.json` | Node 依赖清单 |

## 二、`源码/`（核心代码，就这八个）

| 文件 | 作用 |
| --- | --- |
| `bot.js` | **ai 本体**：连服 / 断线重连 / **正版登录**、指令分发、教学录制、多 ai 管理（summon） |
| `build.js` | **建造核心**：放置/朝向、蓝图、教学复现、检查点、辅助方块 |
| `movement.js` | **移动**：分类注释 【A】基础控制 ~【G】精确落位，见文件头 |
| `rcon.js` | **极简 RCON 客户端**：op、`/give`、`/tp` 都靠它 |
| `config.js` | **统一配置**：读 `config.json` + 深合并默认值 + 旧格式迁移 + 环境变量 / **命令行**覆盖 |
| `access.js` | **准入与失败诊断**（纯逻辑）：自动 op 策略、谁能指挥 ai、连不上 / 被踢的原因 |
| `玩家登记.js` | **玩家与 ai 登记**：谁进过服 / 服主还是成员 / 成员初始 ai 名（`配置/玩家登记.json`），面板按它分服主与非服主 |
| `logger.js` | **日志**：把 console 输出同时写进 `日志/ai_<名字>.log` |

> 入口是 `源码/bot.js`。源码在子目录里，所以代码里取项目根用的是
> `path.join(__dirname, '..')`（`config.json` / `蓝图/` / `教学/` 等都基于它）。
> **有新的可配置项一律加进 `config.js` 的 `DEFAULTS`**，别再散落到各处写死。

### `源码/panel/`（本地 Web 控制面板，零依赖）

| 路径 | 作用 |
| --- | --- |
| `server.js` | 面板本体：`node:http` 起在 `127.0.0.1:8787`，只服务本机（Host 头校验 + 路径穿越保护） |
| `loader.js` | 功能加载器：`api/*.js` 一个文件 = 一个功能，校验 id / `ui.type` / 路由，坏模块只警告 |
| `api/_util.js` | 公共工具：JSON 读写、TCP 探测、日志 tail、`safeFileName` |
| `api/_state.js` | 跨模块共享状态（子进程句柄、输出环形缓冲）——热重载时**故意不重载** |
| `api/_procs.js` | 起停服务器 / ai 子进程、RCON 兜底、读它们的输出、**列出全部 ai**（`aiList`，靠 `ais.json` 的 pid 探活） |
| `api/_fields.js` | 配置字段表（`FIELDS`）+ 点路径读写 / 类型转换；`server.* rcon.* ai.*` 跟着服务器分页走 |
| `api/_profiles.js` | 服务器分页档案（`配置/服务器配置.json`）：新建 / 改名 / 删除 / **应用到 config.json** |
| `api/_settings.js` | 面板**自己的**设置（`配置/面板设置.json`，不是游戏的 `config.json`）：目前存性能检测开关 |
| `api/overview.js` | 功能：概览（`ui.type=cards`） |
| `api/processes.js` | 功能：启动 / 停止（cards，2 秒轮询**只在内容变化时重绘**；两张卡固定高度，按钮行对齐） |
| `api/config.js` | 功能：连接与权限（`custom` → `web/views/config.js`）：多服务器分页 / 服主与非服主视角 / 玩家与 ai 管理 |
| `api/perf.js` | 功能：性能（`custom` → `web/views/perf.js`）：**默认关闭**，开启后给整机 CPU / 内存 / 磁盘 + **面板自己** + **每个 ai** 的 CPU 与内存占用 |
| `api/logs.js` | 功能：日志查看（logs，自动刷新） |
| `api/assets.js` | 功能：蓝图与教学（list，删除=移到 `_回收/`） |
| `api/llm.js` / `api/scriptapi.js` | 规划中的功能占位（前端显示"规划中"） |
| `web/index.html` / `style.css` / `app.js` | 前端：导航 + hash 路由 + 5 种通用渲染器，加功能**不用改这里** |
| `web/views/config.js` / `perf.js` | `custom` 界面的实现（ES module，导出 `render(root, feature)`；公共工具用 `window.panelUI`）；config 里分服主 / 成员两种视角，perf 顶部有开关条 |

> 扩展方式：往 `api/` 丢一个 `.js`，`module.exports = { id, title, order, ui, routes }`
> （完整约定见 `loader.js` 文件头）；特殊界面才用 `ui.type='custom'` + `web/views/<名字>.js`。
> 改完点面板左下角"热重载功能"即可，不用重启面板。
> **面板能改 `config.json`、能起停进程，所以只监听 127.0.0.1，绝不要改成 0.0.0.0。**

## 三、`脚本/`（启动相关）

| 文件 | 作用 |
| --- | --- |
| `start_server.ps1` | **日常**启动服务器（GBK 中文修复 / RCON / 关出生点保护 / `level-name=存档`） |
| `start-server.ps1` | **首次**初始化：下载 server.jar、同意 EULA、设创造+离线 |
| `启动服务器.bat` | 不依赖 PowerShell 的启动（同样带 GBK 参数） |
| `启动面板.bat` | **一键开软件面板**（双击 → 浏览器打开 `http://127.0.0.1:8787/`，关窗口=关面板+停面板拉起的进程） |
| `夜间回归.bat` | **一键跑夜间全量回归**（自动起服务器、逐个跑测试、出报告；见 `测试/夜间回归.js`） |
| `启动.bat` / `run.ps1` | 一键：启服务器 + 启 ai |
| `打包.ps1` | **轻量打包成绿色软件**：复制源码/依赖（裁剪成只要 1.21.1 数据）+ 内置 `node.exe` + 生成 `启动面板.bat`/`启动AI.bat` → `发布\AI-World-<版本>-<Tag>\` 和同名 zip（详见 `README.md`） |

> 脚本会自己 `cd` 到 `../服务器` 再启动 java；ai 用 `../源码/bot.js`。
> ⚠️ **`.ps1` 必须保存为 UTF-8 带 BOM**，否则 PowerShell 5.1 按 GBK 解码，
> 中文注释会被误解析成括号导致 `Missing closing ')'`（踩过）。

## 六、`测试/`（全部测试）

- 跑法：`node 测试/test_xxx.js`（**需要服务器在跑**）。
- 引用写法：`require('../源码/build')`、`require('../源码/movement')`。
- **连接信息统一走 `测试/_common.js`**（它读 `config.json`）：测试里写
  `const { HOST, PORT, VERSION } = require('./_common')`，**不要再写死**
  `localhost` / `25565` / `1.21.1`——换版本、换端口只改配置一处。
- 常用：`test_facing`（朝向）、`test_redstone`（红石）、`test_interactive`（右键可交互方块旁边放方块：
  必须换面或 shift 放，且不能把红石状态改掉）、`test_teach*`（教学）、
  `test_rep`（重复建造）、`test_multi`（多 ai）、`test_land`（落地）、`test_ckstate`（检查点）、
  `test_commands`（聊天指令，含**指令白名单**阶段）、
  **`test_access`（不需要服务器！** 纯逻辑：op 策略 / 指令准入 / 失败诊断 / 命令行参数 / 配置告警）、
  **`test_panel`（不需要服务器！** 面板：功能加载器 / HTTP 接口与安全 / 配置写入与还原）。
- **`夜间回归.js`**：无人值守跑上面**全部**测试（自动起服务器、超时强杀、清残留 ai、
  坏服重启、失败重试），产物在 `日志/夜间回归/`（`最新报告.md` 看结果）。
  `node 测试/夜间回归.js --list` 先看计划，`--reset` 跑干净世界，`--only teach` 只跑一类。
- **`守门.js`**：静态守门，**不用服务器、2 秒**跑完。查语法 / 测试里的指令前缀 /
  `path.`·`fs.`·`spawn(` 有没有 require / require 的相对路径在不在；
  结果写 `日志/夜间回归/最新守门.md`，已排在 `夜间回归.js` 第一位
  （2026-10-31 那次 28 个测试里 17 个失败是"测试自己写坏了"，见 `文档/AI参考.md` 坑 37~39）。

## 七、数据 / 日志目录

| 目录 | 内容 | 说明 |
| --- | --- | --- |

| `发布/` | **打包产物**（`脚本/打包.ps1` 生成） | `AI-World-<版本>-<Tag>/`（绿色软件目录）+ 同名 `.zip` + `发布说明.md`；**gitignore**，发版时把 zip 传到 Release |

## 九、更新约定

1. 新增源码 → 更新"二、`源码/`"。
2. 移动/改名 → 更新对应小节，**并全局搜引用**
   （最容易漏的是 `build.js` 的两个目录常量、测试里的 `require('../源码/...')`、脚本里的路径）。
3. 本文档只描述**结构**；原理和坑写 `AI参考.md`，用法写 `使用说明.md`，方向写 `架构与规划.md`。
4. **改名铁律**：先全局搜引用再改；服务器/依赖规定死的目录名一律不动。
